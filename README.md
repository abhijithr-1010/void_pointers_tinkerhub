### Project Description
A theatrical, single-page fake code editor where the weather controls your editor's mood, colors, animations, and the Malayalam troll-insults it hurls at you. It never compiles real code.

### The Problem (that doesn't exist)
Developers are too productive. They need an editor that actively works against them based on live atmospheric conditions.

### The Solution (that nobody asked for)
Climate Compiler fetches live weather, maps it to one of four climate moods (Rain, Sunshine, Snow, Storm), and then uses that mood to style the background, colors, text physics, ambient sound, and the aggression of the Malayalam meme-insults it fires at your code.
